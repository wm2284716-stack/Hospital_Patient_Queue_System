🏥 Hospital Patient Queue System Project:
It is a C++ application designed to organize patient flow in hospital clinics, serve urgent cases ahead of normal cases while preserving first-come, first-served (FIFO) order for normal arrivals, and store patient records dynamically without fixed limits like traditional arrays.
🧩 Key Components and How It Works:
 * ⏳ Priority-Aware Waiting Queue (Queue.h and Queue.cpp): Manages the patient waiting line so urgent cases are placed ahead and normal cases join at the back, supporting calling the next patient, viewing the front patient, and displaying the queue.
 * 📋 Dynamic Medical Records (LinkedList.h and LinkedList.cpp): Uses a custom singly linked list to store patient records dynamically, preventing duplicate patient IDs, supporting search, update, delete, and display of all records, and cleaning up allocated memory on exit.
 * ⚙️ System Management and Input Validation (Patient.h, HospitalSystem.h, HospitalSystem.cpp, and main.cpp): Separates patient data definitions, system logic, and the interactive console menu into organized files, while validating inputs and handling edge cases such as an empty queue, duplicate IDs, or invalid inputs.
